# Technical assets used by Suite42

These technical-symbol SVG files were copied without geometry changes from the
local Lably project (`public/marks/`): protective-earth, functional-earth,
chassis-ground, equipotentiality, dc, ac, positive-polarity, negative-polarity,
esd, fuse, high-voltage, warning, insulation-class, and fan-cooled.

Catalog labels and applicability notes originate in Lably's
`src/lib/compliance/marks.ts` and `public/marks/SOURCES.md`. These are artwork
resources; insertion does not certify equipment or establish its safety class.
The positive/negative polarity drawings describe a coaxial connector's centre
contact. Class II and ESD-sensitive marks must describe the actual item.
Certification/trademark assets and the entries withheld by Lably are not included.
